Event loop (GameManger 레벨에서)

BATTLE_START
TURN_START
ATTACK  SKILL   ITEM    CHANGE
    CASE ATTACK:
        Pokemon.setHealth(current health - damage)
        if (not enemy alive) {
            ENEMY_DEAD
            BATTLE_END
            GOTO BATTLE_START(line 3)
        }
        break;

    CASE SKILL:
        SKILL.use()
        use가 게임에 영향을 주는 영역에 대해서는 직접 체크
        ex 상대 포켓몬 사망 여부 체크, 이후 ENEMY DEAD RAISE
        break;

    CASE ITEM:
        ITEM.use()
